# Viewer third-party software

- [Chessground 10.1.1](https://github.com/lichess-org/chessground) is licensed
  under GPL-3.0-or-later. It is the board UI bundled into the viewer.
- [esbuild 0.28.2](https://github.com/evanw/esbuild) is licensed under MIT. It is
  a development-only bundler and is not part of the rules core.

The C++ rules library itself has no third-party runtime dependencies.
